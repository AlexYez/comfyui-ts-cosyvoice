#     pip install onnxruntime          # CPU only, or Apple Silicon
#
# It is not listed below on purpose. `onnxruntime` and `onnxruntime-gpu` are two
# separate distributions that both provide the module named `onnxruntime`, and ONNX
# Runtime supports exactly one of them per environment. Listing the CPU build here
# would install it next to a user's existing onnxruntime-gpu, and which one then
# wins is undefined — so the pack asks rather than decides. If it is missing, the
# loader says exactly this instead of failing obscurely, and if CUDA is expected but
# unavailable it says that too rather than quietly running the speech tokenizer on
# the CPU.
#
# torch and torchaudio are likewise absent: ComfyUI installs them as a matched pair
# built against a specific CUDA/ROCm/MPS runtime, and a version line here lets pip
# replace that build. ComfyUI cannot start without them, so there is nothing to
# guard against.

# --- Optional -----------------------------------------------------------------
# None of the following is needed to load a model or to synthesise. Each buys one
# specific extra, and each is left out of the required list for a stated reason.
#
# openai-whisper — automatic transcription of the reference audio into
#   reference_text (Save Speaker, Dialog). Without it those nodes work exactly as
#   before, except you type reference_text yourself.
#   It is optional because it depends on numba, and numba refuses to load against
#   NumPy 2.2 or newer while current ComfyUI ships 2.5. Requiring it would either
#   drag a shared NumPy backwards or break the pack outright. The vendored speech
#   tokenizer used to import it for a mel spectrogram; the pack now computes that
#   itself (utils/ts_mel.py), so whisper is no longer on the synthesis path.
#     pip install openai-whisper
#
# librosa — last-resort pitch shift in the voice conversion node, behind pyworld
#   and torchaudio. Optional for the same numba reason as above.
#     pip install librosa
#
# modelscope — only needed to download from ModelScope instead of HuggingFace.
#   HuggingFace is the default and serves the same files, checked against the
#   same hashes in model_manifest.json, so this is a mirror rather than a
#   second source of truth. Selecting ModelScope without it gives an error
#   that says exactly this.
#     pip install modelscope
#
# pyworld — the formant-preserving (WORLD) pitch shift in the voice conversion
#   node. Without it the node falls back to a phase vocoder and logs which path
#   it took.
#   It is optional because pyworld publishes wheels for Windows only, so on macOS
#   and Linux pip builds a C++ extension from source. That needs the Xcode
#   Command Line Tools on a Mac, and a hard requirement would turn a missing
#   compiler into a failed install of the whole pack.
#     pip install pyworld
