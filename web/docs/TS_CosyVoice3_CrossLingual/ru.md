# TS CosyVoice Cross-Language

Произносит текст на другом языке, сохраняя тембр референсного голоса. Референс может быть на одном языке, а текст — на другом: голос переносится, а произношение следует целевому языку.

## Входы

| Вход | Тип | Обязательный | По умолчанию | Описание |
| --- | --- | --- | --- | --- |
| `model` | COSYVOICE_MODEL | да | — | Загруженная модель CosyVoice из ноды загрузчика. |
| `text` | STRING | да | `Hello, this is cross-lingual speech synthesis.` | Текст, который нужно озвучить на целевом языке. |
| `reference_audio` | AUDIO | да | — | Референсный голос; аудио будет обрезано до 30 секунд и приведено к mono 24 kHz. |
| `speed` | FLOAT | да | `1.0` | Множитель скорости речи на выходе. Диапазон: `0.5`–`2.0`, step `0.05`. |
| `target_language` | COMBO | нет | `auto` | Целевой язык текста; auto пытается определить язык автоматически. Варианты: `auto`, `zh`, `en`, `ja`, `ko`, `de`, и ещё 4. |
| `seed` | INT | нет | `42` | Зерно случайности; значение -1 использует случайный seed. Диапазон: `-1`–`2147483647`. |
| `text_normalize` | BOOLEAN | нет | `true` | Включает нормализацию текста; отключайте для фонем CMU и специальных тегов. |

## Выходы

| Выход | Тип | Описание |
| --- | --- | --- |
| `audio` | AUDIO | Сгенерированная речь с частотой дискретизации модели (24 кГц). |

## Примечания

- Референс обрезается до первых 30 секунд и приводится к mono 24 кГц перед подачей в модель. Чистая речь без музыки и шума клонируется заметно лучше, чем длинный шумный фрагмент.
- Текст пишите сразу на целевом языке — эта нода не переводит. Если нужен перевод, поставьте перед ней ноду-переводчик.
- На CosyVoice3 языковой тег явно не передаётся: модель определяет язык по самому тексту, поэтому target_language важен в основном для более старых чекпоинтов CosyVoice.
- Чтобы получить другой дубль, поставьте у виджета seed режим control_after_generate: randomize. Само по себе значение -1 не помогает: при неизменных входах ComfyUI возвращает результат из кэша, а не запускает ноду заново.
