# TS CosyVoice Speaker Text To Voice

Тот же синтез с инструкцией, что и в TS CosyVoice Text to Voice, но голос берётся из пресета, сохранённого нодой TS CosyVoice Save Speaker, а не из референсного клипа на канвасе. Удобно, когда один голос переиспользуется во многих генерациях.

## Входы

| Вход | Тип | Обязательный | По умолчанию | Описание |
| --- | --- | --- | --- | --- |
| `model` | COSYVOICE_MODEL | да | — | Загруженная модель CosyVoice из ноды загрузчика. |
| `text` | STRING | да | `Hello, this is my cloned voice speaking.` | Текст, который нужно озвучить выбранным сохраненным голосом. |
| `instruct_text` | STRING | да | `Please say this in a warm and soft voice.` | Текстовая инструкция для эмоции и манеры речи; используется только при выборе 'Ваша инструкция'. |
| `speaker_preset` | COMBO | да | — | Выберите ранее сохраненный пресет голоса из папки models/cosyvoice/speaker. Варианты: `Nastya`, `my_speaker`, `my_speaker_v2`. |
| `speed` | FLOAT | да | `1.0` | Множитель скорости итоговой речи. Диапазон: `0.5`–`2.0`, step `0.05`. |
| `seed` | INT | нет | `42` | Зерно случайности; значение -1 использует случайный seed. Диапазон: `-1`–`2147483647`. |
| `text_normalize` | BOOLEAN | нет | `true` | Включает нормализацию текста; отключайте для фонем CMU и специальных тегов. |
| `emotion_preset` | COMBO | нет | `Ваша инструкция` | Готовый пресет эмоции и манеры подачи; при выборе 'Ваша инструкция' используется поле instruct_text. Варианты: `Ваша инструкция`, `Теплый дружелюбный`, `Спокойный мягкий`, `Энергичный выразительный`, `Кинематографичный драматичный`, `Интимный тихий`, и ещё 7. |

## Выходы

| Выход | Тип | Описание |
| --- | --- | --- |
| `audio` | AUDIO | Сгенерированная речь с частотой дискретизации модели (24 кГц). |

## Примечания

- В списке — файлы `.pt` из `ComfyUI/models/cosyvoice/speaker/`. Пока не сохранён ни один пресет, там будет единственный placeholder, а нода попросит сначала выполнить Save Speaker.
- Пересохранённый под тем же именем пресет подхватывается: нода учитывает время изменения файла в ключе кэша и перезапускается, а не отдаёт прежний голос.
- У получателя workflow без этого файла пресета нода не пройдёт валидацию — передавайте `.pt` вместе с графом или попросите пересоздать его через Save Speaker.
- Получить другой дубль можно двумя способами. Значение seed = -1 заставляет ноду выполняться заново при каждом запуске, поэтому каждый прогон даёт новый дубль. При фиксированном seed результат воспроизводим, и ComfyUI отдаёт аудио из кэша, пока ничего не изменилось — поставьте control_after_generate: randomize, если хотите, чтобы сам seed менялся между запусками.
